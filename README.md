# 时间的影子

**[在线试玩](https://wallstreetflypig.github.io/time-shadow/)**

踏上石板，远处的门开了。可当你朝它走去，门又关上了。如果刚才的你能留下来呢？

《时间的影子》是一款五关的浏览器解谜游戏。你控制金色的小人，在浮空石台间探索。每次回溯，你都会回到起点，一个青色影子会重走你刚才的路线。你在哪里转弯、停了多久，它都记得。走到最后一步，它就留在那里。再次回溯，新影子会替换上一个。房间里没有倒计时，可以慢慢试。

## 操作

| 动作 | 键盘 | 触屏 |
| --- | --- | --- |
| 连续移动 | 方向键或 WASD，按住两个方向可斜走 | 按住屏幕方向键 |
| 回溯并生成影子 | 空格 | 点「回溯」 |
| 清空影子，重试本关 | R | 点「重试」 |

每间房都有「查看提示」按钮。首次移动或点击后，主题曲开始播放；回溯和通关各有一段短音效。点击声音按钮可随时静音。

## 五间房

1. **留步** · 一块踏板，一扇松脚就会关上的门。
2. **等我一下** · 两道门之间，停顿也是路线的一部分。
3. **隔岸接力** · 隔岸望去，两边的踏板各管着一段路。
4. **合鸣** · 中庭安静地等着两处回声同时响起。
5. **换你出去** · 最后一间房，为你和影子各留了一个位置。

## 本地游玩

下载仓库中的 `index.html`，双击即可离线游玩。画面由 Canvas 绘制，音乐和音效由 Web Audio API 实时合成。整个游戏都在这一个文件里，无需安装依赖或启动服务器。
